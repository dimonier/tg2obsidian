# tg2obsidian

Эта программа (далее — Бот) использует бесплатную функциональность бота Telegram для сохранения сообщений из группы Telegram в хранилище [Obsidian](https://obsidian.md) на локальном компьютере.

Используемая разметка Markdown подойдёт и для большинства [других программ](https://www.markdownguide.org/tools/), работающих с локальными файлами Markdown.

## Сценарий использования

- Вы _на ходу_ пишете, наговариваете или пересылаете сообщения в личную группу Telegram
- Бот получает новые сообщения из Telegram и сохраняет их в виде заметок, таким образов формируя входящий поток информации прямо в вашем хранилище заметок
- _Позже в спокойной обстановке_ вы обрабатываете эти заметки, разнося информацию из них в подходящие места в своём хранилище

## Возможности

- Возможен приём сообщений из одного или нескольких чатов Telegram.
- Для каждого чата можно указать отдельную папку хранилища Obdisian.
- Все сообщения группируются по дате — одна заметка на день/месяц/год (в соответствии с шаблоном имени заметки) — или хранятся в одной заметке.
- Каждое сообщение в заметке имеет заголовок с отметкой даты и времени (можно подавлять для частых сообщений).
- В зависимости он настроек сохраняется либо игнорируется форматирование сообщений.
- Для пересланных сообщений добавляется информация об источнике сообщения.
- Фотографии, анимации, видео и документы сохраняются в хранилище и встраиваются в заметку.
- Контакты сохраняются в виде YAML front matter и vcard.
- Для мест создаются ссылки на Google Maps и Яндекс.Карты.
- Есть возможность преобразовывать заметки с определенными ключевыми словами в задачу.
- Есть возможность принудительно превращать все сообщения чата в задачи через `/tasks on|off`.
- Есть возможность тегировать заметки с определенными ключевыми словами.
- Есть возможность распознавания текста с картинок. При этом Бот отправляет распознанный текст в виде ответа на исходное сообщение.
- Есть возможность распознавания речи из голосовых сообщений и аудиосообщений (локально через Whisper или через облачный OpenAI-compatible API). При этом Бот отправляет распознанный текст в виде ответа на исходное сообщение.
- После обработки сообщения бот добавляет к нему эмодзи OK.

## Установка и первый запуск

Установите [Python](https://python.org) версии 3.10–3.14 и скачайте проект. Подробная инструкция для Windows со скриншотами есть в [отдельном руководстве](extended_tg2obsidian_manual.ru.md).

Сначала настройте сохранение обычных текстовых сообщений. Распознавание текста и речи можно добавить позже — оно описано ниже.

### 1. Установите необходимые пакеты

Откройте терминал в папке проекта. В Windows используйте командную строку **cmd**, а не PowerShell: команды ниже рассчитаны на неё.

Создайте отдельное окружение для бота, чтобы его пакеты не мешали другим программам:

```shell
python -m venv .venv
```

Активируйте окружение в Windows:

```bat
.venv\Scripts\activate.bat
```

Или в Linux/macOS:

```shell
source .venv/bin/activate
```

Установите пакеты:

```shell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

При каждом новом открытии терминала активируйте это окружение снова. Из него нужно и устанавливать дополнительные пакеты, и запускать бота. Двойной щелчок по `tg2obsidian_bot.bat` окружение не активирует.

### 2. Создайте и настройте бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram, отправьте `/newbot` и следуйте его подсказкам.
2. Скопируйте выданный токен в параметр `token` файла `config.py`. Не публикуйте этот токен и не добавляйте его в коммиты.
3. В том же файле укажите пути к папкам своего хранилища Obsidian:

   - `inbox_path` — куда записывать заметки;
   - `photo_path` — куда сохранять вложения.

   Создайте эти папки, если их ещё нет. Пример для Windows — замените пути своими:

   ```python
   inbox_path = r'C:\Users\you\Documents\MyVault\Telegram'
   photo_path = r'C:\Users\you\Documents\MyVault\attachments'
   ```

   В Linux и macOS укажите свои полные пути, например `/home/you/MyVault/Telegram`.

### 3. Разрешите боту принимать ваши сообщения

Запустите бота из того же терминала:

```shell
python tg2obsidian_bot.py
```

Откройте своего бота в Telegram и отправьте `/start`. Пока чат не разрешён, бот ответит сообщением с его числовым идентификатором.

Остановите бота сочетанием `Ctrl+C`, запишите этот идентификатор в `config.py` и сохраните файл:

```python
allowed_chats = '123456789'
```

Снова выполните `python tg2obsidian_bot.py` и отправьте боту обычное текстовое сообщение. Оно должно появиться в заметке в папке `inbox_path`.

Для нескольких чатов перечислите их идентификаторы через двоеточие: `'123456789:987654321'`. После изменения настроек перезапускайте бота.

## Дополнительные возможности

### Сообщения из группы

Добавьте бота в приватную группу и сделайте администратором, чтобы он мог читать сообщения. Отправьте `/start` в этой группе, добавьте её идентификатор в `allowed_chats` и перезапустите бота. Для начала откройте и личный диалог с ботом, как описано выше.

### Подключение через прокси

Если прямое подключение к Telegram недоступно, укажите прокси в `config.py`:

```python
telegram_proxy_url = "socks5h://your-proxy-host:1080"
telegram_proxy_login = ""
telegram_proxy_password = ""
```

- Оставьте `telegram_proxy_url` пустым для прямого подключения.
- Поддерживаются `socks5h://`, `socks5://`, `socks4a://`, `socks4://` и `http://`.
- Если нужны логин и пароль, заполните `telegram_proxy_login` и `telegram_proxy_password`.
- Прокси используется для подключения к Telegram и скачивания вложений. Предпросмотр внешних ссылок через него не проходит.
- Нужные пакеты уже входят в обычную установку.

Инструкции по настройке VPN и прокси:

1. [Как установить полностью настроенный VPN на VPS](https://github.com/ClusterM/vpn-how-to)
2. [Как настроить SOCKS5 proxy на 3x-ui](SOCKS5-proxy-howto.md)

### Распознавание текста на изображениях

В активированном окружении выполните:

```shell
python -m pip install -r requirements-ocr.txt
```

Установите [Tesseract](https://github.com/tesseract-ocr/tessdoc) с нужными языками и добавьте папку с его исполняемым файлом в PATH. Команда `tesseract --version` должна выводить версию программы.

В `config.py` установите `ocr = True`, настройте `ocr_languages` и перезапустите бота.

### Распознавание речи

По умолчанию голосовые сообщения и аудиозаписи пропускаются. Чтобы получать из них текст, выберите один из двух способов распознавания. Аудиофайлы, отправленные как документы, сохраняются как обычные вложения.

#### На своём компьютере, через Whisper

В активированном окружении выполните:

```shell
python -m pip install -r requirements-voice-local.txt
```

Установите [FFmpeg](https://ffmpeg.org/download.html) и добавьте папку с ним в PATH. Проверьте установку командой `ffmpeg -version`.

В `config.py` укажите:

```python
recognize_voice = True
stt_provider = "local"
```

Перезапустите бота. При первом запуске он скачает выбранную в `whisper_model` модель. Torch и модель могут занимать много места на диске и в памяти.

Whisper и Torch могут поддерживать не все версии Python. Перед установкой сверьтесь с требованиями [Whisper](https://github.com/openai/whisper#setup) и [PyTorch](https://pytorch.org/get-started/locally/). Если хотите использовать видеокарту, следуйте инструкции установки Torch на сайте PyTorch.

#### Через облачный сервис

В активированном окружении выполните:

```shell
python -m pip install -r requirements-voice-cloud.txt
```

В `config.py` установите `recognize_voice = True` и `stt_provider = "cloud"`. Заполните адрес сервиса `stt_base_url`, ключ `stt_api_key`, название модели `stt_model_name` и язык `stt_language`, затем перезапустите бота. Нужен сервис с API, совместимым с OpenAI.

Аудио отправляется выбранному провайдеру. Устанавливать Whisper, Torch и FFmpeg для этого способа не нужно.

Пакеты для распознавания устанавливаются только при необходимости. Каждый файл `requirements-*.txt` также включает обычные зависимости бота; можно установить несколько таких файлов.

## Если бот не запускается

Откройте терминал в папке проекта, активируйте окружение и выполните:

```shell
python -m pip check
python -m unittest discover -s tests -v
```

Первая команда ищет конфликты между установленными пакетами. Вторая запускает три небольших теста: они проверяют загрузку бота, настройку прокси и разбор HTML для предпросмотра ссылок, не обращаясь к внешним сайтам.

Настоящий токен не нужен, сетевых подключений и изменений вашего хранилища нет. Сохранение сообщений и распознавание эти тесты не проверяют. Если возникла ошибка, приложите вывод команд к сообщению разработчику, но не публикуйте токены и пароли из `config.py`.

## Использование

1. Отправляйте/пересылайте сообщения, которые должны попасть в ваше хранилище Obsidian, напрямую вашему боту или в свою приватную группу Telegram.

2. Запустите бота из терминала с активированным окружением:
```shell
python tg2obsidian_bot.py
```

- На постоянно работающем компьютере или на сервере Бота можно не выключать. Тогда он будет распознавать речь и заносить заметки в Obsidian в реальном времени.
- Если вы включаете компьютер только на время использования, запускайте Бота непосредственно тогда, когда нужно получить сообщения в Obsidian, а после получения всех сообщений закрывайте программу.

**Важно!** Telegram хранит [новые сообщения](https://core.telegram.org/bots/api#getting-updates) для ботов в течение 24 часов, поэтому Бот может получить сообщения только за последние 24 часа. Если от момента отправки сообщения до запуска Бота прошло более 24 часов, такое сообщение уже не будет получено Ботом.

### Команды бота

- `/start` — показывает id чата для `allowed_chats`.
- `/help` — помощь.
- `/set_folder <path>` — задать относительную папку для текущего чата.
- `/tasks on|off` — принудительно делать все сообщения чата задачами (с суффиксом задачи).

### Группировка по времени

Чтобы не повторять заголовок с временем при серии сообщений, добавьте `message_timestamp_interval` в `config.py` (секунды). Если сообщение пришло в пределах интервала, заголовок времени не добавляется.
